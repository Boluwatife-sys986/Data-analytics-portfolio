# Sales Performance Dashboard

## Project Overview

This project analyzes retail sales performance using Power BI.

## Tools Used

- Power BI
- DAX
- Power Query

## Key Metrics

- Total Sales
- Total Profit
- Profit Margin

## Business Insights

- Identified highest-performing sales regions.
- Analyzed monthly sales trends.
- Identified top-performing products.

## Skills Demonstrated

- Data Visualization
- Dashboard Development
- Business Intelligence
- DAX Calculations
