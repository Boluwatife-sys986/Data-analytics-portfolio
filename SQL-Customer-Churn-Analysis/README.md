# Customer Churn Analysis (SQL Server)

## Project Overview

This project analyzes customer churn using SQL Server and a dataset containing 10,000 customer records.

## Tools Used

- SQL Server
- SSMS
- T-SQL

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT
- AVG

## Analysis Performed

### Churn Rate Analysis

Calculated total churned customers and churn percentage.

### Geography Analysis

Identified countries with the highest customer churn.

### Customer Activity Analysis

Analyzed active vs inactive customers.

### Salary Analysis

Compared average salary by geography.

### High Value Customers

Identified customers with the highest account balances.

## Key Findings

- Approximate churn rate: 20%
- Germany and France recorded the highest churn.
- Active customers represented over 50% of the dataset.
- Several high-value customers maintained balances above 200,000.
